# OkBite

A mobile app for iPhone and Android: photograph a food product in Moldova and see what the label really says (allergens, a nutrition score with reasons, every ingredient explained). Products not yet in the database are added from a photo of their label.

Status: planning. The code is built by five people, each using Claude Code and Codex, one role each:

- Spec: `docs/superpowers/specs/2026-11-03-okbite-design.md`
- Overall plan and the 5 roles: `docs/superpowers/plans/2026-11-04-okbite-overall.md`
- Knowledge graph of the plan: `graphify-out/graph.html`, `graphify-out/GRAPH_REPORT.md`
- Rules for AI agents: `AGENTS.md`
- Prototype source: `docs/prototype/`

Target public launch: 8 December 2026.
