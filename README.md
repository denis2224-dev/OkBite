# OkBite

A mobile app for iPhone and Android: photograph a food product in Moldova and see what the label really says (allergens, a nutrition score with reasons, every ingredient explained). Products not yet in the database are added from a photo of their label.

Status: planning. The code is built by four people with Claude Code and Codex, lane by lane:
