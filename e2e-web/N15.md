## Changes and rulings

- Existing Home installation invitation now explicitly opens a rounded bottom
  sheet with scrim, themed home icon, title, current benefit description, and
  inset iPhone Share → Add to Home Screen guidance. Android installation keeps
  the existing direct invitation action; a rejected install opens the sheet with the existing error message.
- Ruling: retain an explicit invitation instead of automatically opening an iOS
  modal — an automatic modal would obstruct existing startup and browser flows.
  The root agent approved this choice. Cost: iPhone guidance requires an
  additional tap; visual comparison should include the opening invitation.
- Ruling: preserve Android direct installation on the invitation's first press
  — the existing lifecycle contract and button wording imply immediate install.
  The root agent narrowed the earlier sheet proposal accordingly. Cost: Android
  shows the browser's own install confirmation instead of an extra app sheet.
- Dismissal keeps the existing `okbite.install.dismissed.v1` persistence and
  in-session fallback. Closing or Escape remembers dismissal; explicit reopening
  never resets it. Native installation remains inert.
- `useInstallPrompt().openSheet()` can reopen guidance from future Settings
  integration; Android uses the existing provider `install()` action directly.
  It requires one mounted `InstallPrompt` host in the same existing provider.
  No N8 wiring is included; Home currently owns the only host, so a Settings
  route that unmounts Home will need its owner to place a persistent host.
- Manifest shortcut `Scanează` points to `/`, which becomes Scan after N9.
  Existing colors already match `light.primary`/`light.ground`; icons are unchanged.
- No backend contracts, application copy, preference resets, invented products,
  nutrient values, or new dependencies are included.
