# Copy and accessibility acceptance — November 2026

Prepared 8 November. Reused from 712db57. The apps/mobile PWA is the acceptance target; root routes below remain reference-only. All physical checks below are **NOT RUN**. Automated
component/contrast tests and JavaScript exports do not establish phone acceptance.

## How to record each screen

Run on an installed staging build on an iPhone and Android phone, then Safari
and Chrome on those phones. For every screen/state below, record separately:
SHA, build ID, date, tester, device model, OS/browser version, appearance and
font setting, result for each check, issue ID/owner and restricted evidence path.
Use `PASS`, `FAIL` or `BLOCKED` only after execution; otherwise `NOT RUN`.
Keep personal data, real photos and tester contact details outside Git.

Apply all of these checks to **every** screen/state:

1. A Romanian-speaking human reads all copy in context: diacritics, labels,
   decimal commas, validation, plural forms, offline/retry explanations. Missing
   nutrients stay missing; explanations and disclaimer remain beside scores.
2. Light and dark modes: readable text, icons, inputs, banners and selected states.
3. At 200% system text/browser text zoom: no clipped copy, hidden actions, overlap,
   inaccessible scrolling, truncated values or modal/keyboard obstruction.
4. VoiceOver and TalkBack: Romanian accessible names/roles, meaningful order,
   headings, value/selected/disabled state, errors and loading announcements;
   decorative icons do not repeat labels. Navigation does not strand focus.
5. Interactive targets measure at least 44 × 44 logical points/CSS pixels, including
   back, close, tabs, chips, gallery, clear and tiny source/report links.
6. Text contrast is at least 4.5:1 in both themes, including muted text/placeholders;
   statuses and errors have text as well as color. Measure actual rendered colors.
7. Phone browsers: visible keyboard focus, Enter/Space activation, correct link
   behavior, safe areas and unobscured focus with the keyboard/footer showing.
